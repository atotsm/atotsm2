# ATOTSM2 — Systems, flourishing and practical alternatives

Second-generation static website for ATOTSM.

## Pages
- index.html — integrated overview
- usurology.html — systemic conditions, institutions, money, ownership and power
- ikigaiology.html — human needs, purpose and meaningful flourishing
- laboratory.html — complementary currencies, community design and experiments
- method.html — evidence standards, hypotheses, counterarguments and revision
- assets/site.css and assets/site.js — shared responsive design and navigation

## Intellectual posture
Usurology and Ikigaiology are presented as proposed, evolving fields of inquiry, not established academic consensus. The site distinguishes research questions and design hypotheses from findings. Debt-based money is an important research thread, not a universal explanation.

## Preview
Open index.html in a browser. No build tools or runtime are required.
