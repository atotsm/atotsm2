# ATOTSM — Usurology × Ikigaiology

A new, independent presentation of two complementary proposed fields of inquiry:
- **Usurology:** understanding the systems and conditions shaping human life.
- **Ikigaiology:** exploring meaningful human flourishing.

The site is intentionally open-ended. It distinguishes evidence, interpretation,
hypothesis, proposal, counterargument and revision rather than presenting the
framework as established academic consensus.

## Development

This is a static website. Open `index.html` in a browser.

## Deployment

Hosted with GitHub Pages from the root of the `main` branch.
